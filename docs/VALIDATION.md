## 接口与执行边界测试

- 页面不再挂载全局访问密钥拦截；Home Assistant 设置保留原布局，设备访问通过登录后的启用按钮确认，无需访问密钥。
- 未登录访问应用页面跳转登录；登录 / 回调、法律条款与静态资源不拦截。伪造 Cookie 不能绕过网关。
- 未登录业务 API 返回 401，游客聊天 / 额度 / 语音和游客导入在登录后也返回 404，不转发云端、不接触 HA。
- 无需额外本地密钥即可登录云端、读取账号 / 记忆；设备状态、地址、白名单、读取与控制仍受家庭授权隔离。
- 登录后无家庭授权时，消息仅发送专用纯聊天端点；验证 SSE、重生成字段、查询参数清除和 Cookie 隔离。云端缺失该端点时明确返回 503，不回退旧聊天接口。
- 给已登录浏览器启用 HA 后保留云端身份；未登录、跨站和无 Origin 启用请求拒绝，额外 JSON 字段拒绝。原本地工具往返、请求去重与设备控制回归通过。
- 退出登录后业务 API 失效，重新登录或切换账号不继承此前的设备授权。前端移除游客入口、匿名 API 分支和游客历史导入；已过期或伪造的 Cookie 不能读取应用页面。

- 原登录 / refresh API 返回本地会话标记，不向浏览器泄露云端 JWT 或 refresh Cookie。Google 登录往返只兑换一次性授权码，不提交 Clerk Session Token，错误的 state 和重复授权码不会再次兑换。
- Google 登录修复：Private 官网新增授权页及授权 / 兑换接口；使用 miniredis、临时账号和真实 Public 网关完成 PKCE 兑换、本地会话账号读取及回调重放测试。云端测试覆盖两分钟过期、并发单次消费、客户端 / 回调 / PKCE 绑定和本地地址限制；前端覆盖账号选择、授权意图过期、非法参数及回调篡改。尚未部署或登录真实 Google 账号。
- 原记忆 / 账号读取请求由后端带云端凭证代理；设置中的 HA 配置以本地授权覆盖。
- 原聊天消息 API 进入 Local 工具循环，输出 SSE token / done 事件；重复发送不重复控制设备。
- 原家庭页面 API 仅访问本地 HA；未授权实体拒绝，原 FRP 授权端点不转发云端。
- Next.js 页面与 `/_next` 资源由网关代理，不被 API 适配截获。
- 保留原工具循环测试：重复 / 并发请求去重、结果回传失败后的防重放、过期调用和请求归属检查。
- 保留 HA 实体 / 服务 / 参数白名单、目标覆盖拒绝、状态回读、Token 重定向保护及本地同源 / Host 检查。
- 适配原灯光参数的形状与范围测试通过。
