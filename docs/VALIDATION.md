## 接口与执行边界测试

- 页面不再挂载全局访问密钥拦截；Home Assistant 设置保留原布局，设备访问通过登录后的启用按钮确认，无需访问密钥。
- 未登录访问应用页面跳转登录；登录 / 回调、法律条款与静态资源不拦截。伪造 Cookie 不能绕过网关。
- 未登录业务 API 返回 401，游客聊天 / 额度 / 语音和游客导入在登录后也返回 404，不转发云端、不接触 HA。
- 无需额外本地密钥即可登录云端、读取账号 / 记忆；设备状态、地址、白名单、读取与控制仍受家庭授权隔离。
- 登录后无家庭授权时，消息仅发送专用纯聊天端点；验证 SSE、重生成字段、查询参数清除和 Cookie 隔离。云端缺失该端点时明确返回 503，不回退旧聊天接口。
- 给已登录浏览器启用 HA 后保留云端身份；未登录、跨站和无 Origin 启用请求拒绝，额外 JSON 字段拒绝。原本地工具往返、请求去重与设备控制回归通过。
- 退出登录后业务 API 失效，重新登录或切换账号不继承此前的设备授权。前端移除游客入口、匿名 API 分支和游客历史导入；已过期或伪造的 Cookie 不能读取应用页面。
