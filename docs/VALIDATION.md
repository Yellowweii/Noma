## 接口与执行边界测试

- 页面不再挂载全局访问密钥拦截；Home Assistant 设置保留原布局，仅在设备授权处输入本地密钥。
- 无本地会话可请求游客聊天 / 额度，SSE 回复和签名额度 Cookie 保留，不接触 HA。
- 无本地密钥可登录云端、读取账号 / 记忆；设备状态、地址、白名单、读取与控制仍受家庭授权隔离。
- 登录后无家庭授权时，消息仅发送专用纯聊天端点；验证 SSE、重生成字段、查询参数清除和 Cookie 隔离。云端缺失该端点时明确返回 503，不回退旧聊天接口。
- 给已登录浏览器授权 HA 后保留云端身份；错误密钥拒绝。原本地工具往返、请求去重与设备控制回归通过。

- 原登录 / refresh API 返回本地会话标记，不向浏览器泄露云端 JWT 或 refresh Cookie。
- 原记忆 / 账号读取请求由后端带云端凭证代理；设置中的 HA 配置以本地授权覆盖。
- 原聊天消息 API 进入 Local 工具循环，输出 SSE token / done 事件；重复发送不重复控制设备。
- 原家庭页面 API 仅访问本地 HA；未授权实体拒绝，原 FRP 授权端点不转发云端。
- Next.js 页面与 `/_next` 资源由网关代理，不被 API 适配截获。
- 保留原工具循环测试：重复 / 并发请求去重、结果回传失败后的防重放、过期调用和请求归属检查。
- 保留 HA 实体 / 服务 / 参数白名单、目标覆盖拒绝、状态回读、Token 重定向保护及本地同源 / Host 检查。
- 适配原灯光参数的形状与范围测试通过。
